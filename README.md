</h1>NITC track made for tuxKart</h1>

**Installation of the Track**

download the "Track/NITC-FOSS" folder from repository and paste it in 
your supertuxkart's "..data/tracks" folder.

you can find the track in your game under "Duffy-NITC"
You shoud be good to go !!

![MainEnterance](https://github.com/user-attachments/assets/b9b396f6-cc92-44ff-9030-08d9723833ab)

The track contains the STK drivelines, checklines and tyre barriers with custom textures.

**Getting KSRTC the kart**
You can get your hands on the KSRTC model karts from https://github.com/bRuttaZz/kart-ksrtc (thanks to @bRuttaZz) by following the provided simple instructions 

**Tooling and Customizing the track**

The blend files are present for the purpose which can be downloaded from this repository under the blends folder. It contains the necessary textures and objects needed for the current version of the track

Presequisites:
  Blender 3.6 or above
  STK addons and tools
  Media repository from the SVN subversion (can be found out from STK's )
  SVN subversion toolkit for installing and maintaining the media library

For more informantion on creating your own tracks for SuperTuxKart, you can visit the offcial STK site : https://supertuxkart.net/Making_Tracks
